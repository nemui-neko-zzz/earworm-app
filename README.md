# よしなしおと

ふと浮かんだ音楽を記録し、あとから自分の記憶・感情・関心を振り返るための個人用Webアプリです。

## 公開URL
GitHub Pagesを有効にすると、通常は https://nemui-neko-zzz.github.io/earworm-app/ で利用できます。

## 現在の機能
- 日付・時刻・曲名・アーティスト・コメントの記録
- 記録の編集・削除
- MusicBrainzでの曲検索（通信できない場合は手入力）
- 記録数、アーティスト、時間帯の簡易統計
- AI分析用テキストの生成（自動送信なし）
- JSONバックアップの書き出し・読み込み、CSV書き出し

## データとプライバシー
- 記録データは利用中のブラウザのlocalStorageに保存します。GitHubへ記録内容が送信される設計ではありません。
- ブラウザのサイトデータ削除や端末故障などで記録が失われる可能性があります。定期的にJSONバックアップを保存してください。
- 曲検索時は入力した検索語をMusicBrainzへ送信します。
- AI分析用テキストは自動送信しません。内容を確認してから手動で利用してください。

## 開発状況
初期開発版。iPhone Safariを含む実機テスト、検索APIの動作、入力UIの細部は継続確認が必要です。特に時刻入力の5分刻みはブラウザのUI実装によって表示が異なる場合があります。
